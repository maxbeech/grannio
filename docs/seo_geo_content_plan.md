# Grannio — Hybrid Search Content Matrix (SEO + GEO)

The single brief reference for writers. Every piece pins a **Keyword** (what Google matches) and an **Entity Focus** (the context an AI model needs before it will cite us). Volumes are Google Ads US monthly averages; "comp" is the Ads competition index — an advertiser signal, not organic difficulty, so treat soft terms as winnable. Write to the entity, not the string: define the thing, name what it connects to, and the citation tends to follow.
